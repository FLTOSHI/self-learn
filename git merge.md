Используется для объединения одной или нескольких веток в текущую рабочую ветку. Находит общий базовый коммит веток, после чего объединяет различия и создает новый коммит слияния (merge commit), сохраняя историю и контекст.

Обычно её используют для слияния веток с фичами в главную.

Если ветка (target branch), в которую вливают изменения не менялась, Git просто перемещает указатель вперёд, без коммита слияния. (т.н Fast-Forward)

Используется следующим образом: 
`git checkout <target_branch>` - переход на ветку, куда будет мёрдж
`git merge <source_branch>` - слияние изменений из другой ветки
