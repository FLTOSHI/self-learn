Слияние в Git - процесс соединения изменений в одной ветки в другую. Во время обновления одной (целевой) ветки из другой (исходной), нужно оформить слияниее. Слияние включает в себя разрешение конфликтов между ветками, если они существуют. Цель слияния - создать новый коммит, который отражает в себе совместные изменения из обоих веток в одну.
