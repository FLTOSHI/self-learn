Для управления локальными и глобальными настройками Git, можно использовать [[git config]] с опциями `--local` и  `--global`:

- Локальный конфиг:  `git config --local [key] [value]` для определения настроек в **текущем репозитории**
- Глобальный конфиг: Use `git config --global [key] [value]` для определения глобальных настроек которые применяются ко **всем репозиториям** в системе.
