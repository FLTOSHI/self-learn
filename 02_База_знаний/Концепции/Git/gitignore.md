Есть файлы, которые не должны светиться в репозиториях - кэш Python, переменные окружения, секреты (по типу ключей шифрования). Чтобы избежать ситуаций, когда они попадают в репозиторий, их включают в .gitignore файл, который находится в корневой папке проекта.

Файл описывает шаблоны, которые Git должен игнорировать, уже отслеживаемые он не трогает, их следует для начала удалить из индекса с помощью `git rm --cached`.

Базовые шаблоны можно брать из репозитория `github/gitignore`, там есть файлы для популярных языков и IDE.
