Три ключевых этапа разработки: изменить -> индексировать -> закоммитить.

- Edit (Изменение) - внесение изменений в локальном репозитории: создать, удалить файл, изменить строчку кода, заставить что-то работать так, как надо. На этом этапе Git не видит изменений.
- Stage (Подготовка, индекс) - git add переносит изменения в область подготовленных файлов (Staging Area), отметка файлов как готовых к коммиту.
- Commit (Фиксация) - git commit берёт всё из индекса, фиксирует локально с уникальным ID и сообщением.
- Push (Отправка) - git push отправляет коммит на удалённый репозиторий.
