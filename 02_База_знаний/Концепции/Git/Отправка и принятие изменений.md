Во время подтягивания изменений с  помощью `git pull`, разработчик  также извлекает и интегрирует изменения из удаленного в локальный репозиторий. Эта операция обновляет локальную ветку с последними изменения из удаленной ветки.

Во время отправки изменений с помощью `git push`, разработчик отправляет свои локальные изменения в удаленный репозиторий, который может быть как на GitHub, GitLab, Bitbucket. 

Такой операцией разработчик обновляет удаленный репозиторий своими изменениями.
