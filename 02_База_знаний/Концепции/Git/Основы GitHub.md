Основные фичи и функционал, которые являются базой системы контроля версий и платформой для коллабораций GitHub. 

Эти основы включают в себя репозитории, ветки, пул реквесты для код ревью и слияния, недочёты для отслеживания задач и багов, инструменты для коллабораций как доски и вики.

Понимание и умение пользоваться этими фундаментальными компонентами позволяет разработчикам эфектвно управлять проектами, взаимодействовать с коллегами и участвовать в опен-сорс инициативах.
