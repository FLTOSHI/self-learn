При создании нового проекта понадобится использовать команды `git init` для инициализации репозитория (хранилища всей кодовой базы проекта, файлов для него и его документации) и записывать изменения с помощью `git add`.

Как только понадобиться сохранения изменения для последующей отправки в репозиторий, используется команда `git commit`

Если что-то пошло не так, `git reset` или `git revert` для изменения.

Также можно взаимодействовать с удаленным репозиториями, в зависимости от их настроек приватности путем добавления ремоутов `git remote add` и управляя их соединениями командами `git fetch`, `git push` и `git pull`.
