Git предоставляет инструменты для совместной работы:
- Форк репозитория используя  через `git fork`.
- Клонированиее репозитория через `git clone`.

Если коротко: если клонировать чей-то проект, то только локально, без заливания в оригинальный репозиторий (если нет прав, разумеется), а форк - для независимого развития проекта, если автор оригинала дурак, но можно делать пулл реквесты.
