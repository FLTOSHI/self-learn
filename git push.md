Используется для отправки коммитов из локального репозитория в удалённый.

Используется следующим образом:
- `git push` - отправляет текущую ветку в репозиторий.
- `git push origin <branch_name>` - отправляет конкретную ветку.
- `git push -u origin <branch_name>` - отправляет в конкретную ветку и делает её отслеживаемой (чтобы потом просто `git push` использовать).
