# 📚 2. Каждая тема должна иметь своё место

Теперь важно понять, куда пойдёт каждая тема из списка.

## **Документация (01_Документация/Git)**

Сюда идут практические, справочные вещи:

- git init
- git config
- Staging Area
- Коммиты
- Ветки
- Merge
- Checkout

Например:
```Code
01_Документация/Git/git_init.md
01_Документация/Git/git_config.md
01_Документация/Git/Staging_Area.md
01_Документация/Git/Commit.md
01_Документация/Git/Branches.md
01_Документация/Git/Merge.md
```

## **База знаний (02_База_знаний/Концепции)**

Сюда идут фундаментальные понятия:

- Что такое система контроля версий
- Почему стоит их использовать
- Git vs другие системы
- Что такое репозиторий
- Что такое рабочая директория
- Что такое staging

Например:
```Code
02_База_знаний/Концепции/Что_такое_Git.md
02_База_знаний/Концепции/Что_такое_репозиторий.md
02_База_знаний/Концепции/Рабочая_директория.md
```

## **Инструкции (04_Инструкции)**

Сюда идут пошаговые рецепты:

- Как инициализировать репозиторий
- Как сделать коммит
- Как создать ветку
- Как удалить ветку

04_Инструкции/Как_удалить_ветку.md

# 🧩 3. Как связать всё вместе

Каждый пункт из твоего списка должен:

1. быть отмечен в roadmap
2. иметь заметку в нужной папке
3. быть связан ссылкой

Например:
	В roadmap:
```Code
- [ ] git init → [[git_init]]
```

	В заметке:
```markdown
# git init

## Описание
Инициализация нового репозитория.

## Команда
git init

## Когда использовать
...
```

# Как двигаться дальше без перегруза

### **Шаг 1. Берёшь первый пункт из roadmap**
	Например: «Что такое система контроля версий?»
### **Шаг 2. Создаёшь заметку в База знаний**
	`02_База_знаний/Концепции/Что_такое_СКВ.md`
