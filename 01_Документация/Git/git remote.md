Используется для управления ссылками (ремоутами) на удаленные репозитории (GitHub, GitLab и т.д), позволяет присваивать имена источникам, избавляя от необходимости использовать URL-адрес при использовании команд [[git fetch]], [[git pull]] и [[git push]].

Часто используется со следующими опциями:
- `git remote` - список названий или с опцией `-v` для получения списка с URL-адресами.
- `git remote add <name> <url>` - добавление и привязка нового источника
- `git remote remove <name>` - удаление источника
- `git remote show <name>` - данные по источнику.
