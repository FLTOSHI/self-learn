Команда, позволяющая смотреть, создавать или удалять ветки, но не позволит бегать по веткам, смотреть и насиловать ветки можно через `git checkout` и `git merge`.

Используется так:
- `git branch` - показывает все ветки в репозитории. Ровно также можно через `--list`
- `git branch <name>` - создать репозиторий
- `git branch -d <name>` - удаляет указанную ветку. Безопасно, предостерегая от удаления ветки, если в ней есть несмерженные изменения
- `git branch -D <name>` - тоже, но без оглядки на изменения.
- `git branch -m <name>` - переименовать текущую ветку во что-то другое.
- `git branch -a` - все удаленные ветки
