Ключевая команда, которая делает запись изменений. Коммитить можно как файл (причем даже один пробел), так и весь проект целиком. Последняя команда в конвеере "Edit, Stage, Commit".

Часто используется `git commit -m "Сообщение"`.

Также существует команда `git commit --amend`, которая позволяет изменить последний коммит (отредактировать его).
