Команда для отмены локальных изменений, перемещения указателя HEAD и сброса состояния рабочей директорий (индекса) до определенного коммита.

Часто используется следующим образом:
- `git reset --soft <commit>` - переносит указатель на указанный коммит, но оставляет изменения в индексе и рабочем каталоге. 
- `git reset --mixed <commit>` - переносит указатель и сбрасывает индекс, но оставляет изменения в рабочем каталоге 
- `git reset --hard <commit>` - переносит указатель, индекс и рабочую директорию. **Всё** незакоммиченное будет  **удалено**.
- `git reset HEAD~1` - удаляет последний коммит, оставляя файлы из него в рабочем каталоге.

Для безопасной отмены лучше использовать [[git revert]]
