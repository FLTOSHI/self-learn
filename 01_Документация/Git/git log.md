Используется для просмотра истории коммитов в репозитории Git. Показывает хэш коммита, автора, дату и сообщение от самого последнего коммита назад по истории.  
По умолчанию отображает все коммиты текущей ветки в обратном хронологическом порядке.  
Обычно применяется для анализа изменений, поиска конкретных коммитов или понимания истории проекта.

Используется следующим образом:
```
git log                    # Полная история текущей ветки
git log --oneline          # Краткая история (одна строка на коммит)
```

```
git log                    # Детальная история с полями: хэш, автор, дата, сообщение
git log --oneline          # Короткий хэш + сообщение (удобно для обзора)
git log -n 5               # Последние 5 коммитов
git log <file>             # История изменений конкретного файла
```

|Опция|Описание|Пример|
|---|---|---|
|`--oneline`|Короткий хэш + сообщение|`git log --oneline`|
|`--graph`|Графическое отображение веток|`git log --graph --oneline`|
|`--decorate`|Показывает имена веток/тегов|`git log --oneline --decorate`|
|`-p`|Показывает diff каждого коммита|`git log -p`|
|`--stat`|Статистика изменений по файлам|`git log --stat`|

```
git log --oneline --graph --decorate --all
```

Мини-шпаргалка
- Основное: `git log`, `git log --oneline`
- Полный обзор: `git log --oneline --graph --decorate --all`
- Diff изменений: `git log -p`
- Статистика: `git log --stat`
- Поиск: `git log --grep="..."`, `git log -S"строка"`
- Ограничение: `git log -n 10`
