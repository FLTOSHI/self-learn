Команда, используемая для перемещения изменений из рабочей директории в staging area (он же индекс). Это первый шаг в конвеере "edit, stage, commit" для подготовки содержимого к коммиту.

Обычно используется `git add .` для подготовки **всех** файлов к коммиту, но можно использовать `git add -p file`, если нужно закоммитить что-то определенное.
