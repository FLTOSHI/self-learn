## Описание
Модификация для мода "Better Than Adventure!", которая портирует функционал из современных версий Minecraft.

## Цели
- Изучить работу с движками для модификаций Minecraft (а точнее с Babric (форк Fabric))
- Попрактиковаться в Java-программировании
- Внести себя в коммунити BTA!

## Статус
#Заморожен, из-за армии и нехватки скилла в рисовании и программировании на Java
